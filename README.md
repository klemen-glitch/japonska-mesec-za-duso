# Japonska — Mesec za dušo 🍁

Statičen potovalni vodnik za potovanje po Japonski (3. 11.–2. 12. 2026),
pripravljen za Magdo in prijateljice. Deluje tudi brez interneta (PWA).

- **Stran:** `japonska-2026-stran/` (HTML/CSS/JS, brez ogrodja)
- **Generator:** `generator/` (Python skripte + podatki, ki ustvarijo strani)

## Objava
Stran je statična. Objavi mapo `japonska-2026-stran/`.
Na Netlifyju je pot nastavljena v `netlify.toml` (publish = `japonska-2026-stran`).

## Posodobitev vsebine
Uredi podatke v `generator/` in poženi `python3 generator/gen.py`.
